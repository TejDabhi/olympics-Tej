# 🏅 Olympics Data Analysis

A modern Olympics Data Analysis project built to explore historical Olympic datasets, athlete performance, medal trends, country-wise statistics, and sports insights using data analysis and visualization techniques.

---

## 🚀 Features

- 📊 Olympics dataset analysis
- 🥇 Medal tally visualization
- 🌍 Country-wise performance insights
- 👨‍💼 Athlete statistics and records
- 📈 Interactive charts and graphs
- 🔍 Data filtering and exploration
- 📱 Responsive and user-friendly interface

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/TejDabhi/olympics-Tej.git
```

Move into the project directory:

```bash
cd olympics-Tej
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python main.py
```
